# Imported champion programs

These contest programs were supplied by the team from local downloads. They
are preserved as additional variants and should not be overwritten:

- `solutions/reverse-a-list/champion-96523a5b.man`, imported from
  `~/Downloads/reverse-a-list-96523a5b.man`.
- `solutions/triangle/champion-2b3ad36a.man`, imported from
  `~/Downloads/triangle-2b3ad36a.man`.

The reverse-list program is especially useful as a compact reference for
bounded FIFO/reversal work: it combines `Y`-forked workers, pipe contention,
and a small control room instead of an addressable RAM belt. The triangle
program is a useful minimum-layout reference for folding compute and I/O rooms
into the same box.
